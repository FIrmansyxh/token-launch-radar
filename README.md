A dashboard that ranks the protocols which have no token yet by what a launch would be worth, with an implied value, a confidence range, the factors behind it, the risks against it and a farm plan for each one. It separates protocol-owned TVL from depositor capital, pegged TVL and network stake, so a vault curator's depositors are not priced like a DEX's own pools.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
